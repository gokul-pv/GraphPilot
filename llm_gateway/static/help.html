📚 LLM Gateway · Help

Dashboard Help

This service routes LLM calls across six providers — five free-tier or local, plus metered W&B Inference — with automatic failover, rate-limit tracking, persistent logging, and a manual override. Below: how to use it, what each provider offers, and how to get keys.

Using the gateway

Python (built-in client)

from client import LLM, ask

# one-shot
print(ask("Explain transformers in 3 lines"))

# explicit provider (shortcut keys: g, n, o, gr, w, or)
print(ask("hi", provider="gr"))   # groq
print(ask("hi", provider="g"))    # gemini

# full client
llm = LLM()
r = llm.chat("hi", provider="gemini", max_tokens=128, temperature=0.5)
print(r["text"], r["provider"], r["latency_ms"])

# streaming
for chunk in llm.stream("count to 5"):
    print(chunk, end="", flush=True)

HTTP (OpenAI-style)

curl http://localhost:8109/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"prompt": "hello", "provider": "g", "max_tokens": 128}'

Without provider, the gateway tries them in failover order (configurable via LLM_ORDER in .env). Explicit provider = no failover (errors surface immediately).

Provider overview

1. Gemini (Google AI Studio)

  • Best models: gemini-3.1-pro-preview, gemini-3.1-flash-lite-preview ★ default, gemini-2.5-flash, gemini-2.5-pro
  • Context: 1M tokens in / 65K out
  • Free tier (Flash-Lite): ~15 RPM · 250K TPM · 1,000 RPD
  • Pro models: 5 RPM · 25 RPD (very tight)

Get a key:

  1. Go to aistudio.google.com/app/apikey
  2. Sign in with your Google account
  3. Click Create API key → pick or create a project → copy the AIza… key
  4. No credit card required for free tier

2. NVIDIA NIM (build.nvidia.com)

  • Top 100B+ models: deepseek-ai/deepseek-r1 (671B MoE) ★, meta/llama-3.1-405b-instruct, nvidia/llama-3.1-nemotron-ultra-253b-v1, deepseek-ai/deepseek-v3.2 ★ default
  • 187 models in catalog total
  • Free tier: 40 RPM, 1,000 inference credits on signup (request up to 5,000)
  • OpenAI-compatible

Get a key:

  1. Go to build.nvidia.com
  2. Sign in (free NVIDIA Developer Program)
  3. Pick any model → click Get API Key → copy the nvapi-… key
  4. No credit card required

3. Groq fastest cloud

  • Top models: llama-3.3-70b-versatile ★ default, openai/gpt-oss-120b, openai/gpt-oss-20b, meta-llama/llama-4-scout-17b-16e-instruct, qwen/qwen3-32b, groq/compound
  • Speed: 300+ tokens/sec on Llama 3.3 70B
  • Free tier: 30 RPM · 6,000 TPM · 1,000 RPD (RPD is the binding limit; ~500K tokens/day for 70B)
  • OpenAI-compatible

Get a key:

  1. Go to console.groq.com
  2. Sign in with Google or GitHub
  3. API Keys → Create API Key → copy the gsk_… key
  4. No credit card required

4. W&B Inference metered

  • Models: zai-org/GLM-5.3-Flash ★ default (1M ctx, vision), openai/gpt-oss-20b ★ router default, openai/gpt-oss-120b, deepseek-ai/DeepSeek-V4-Pro-0813 (1M ctx), moonshotai/Kimi-K2.7-Code, Qwen/Qwen3.8-27B, meta-llama/Llama-3.3-70B-Instruct
  • The only paid provider in the ring. GLM-5.3-Flash bills $0.15 / $0.50 per Mtok (in / out); gpt-oss-20b is $0.03 / $0.13
  • No published RPM/TPM/RPD. The only documented limits are a monthly spend cap (default $100/mo on Free, $6,000/mo on Pro) and an undocumented concurrency limit returning 429 Concurrency limit reached
  • The gateway does not cap spend — it throttles requests and tokens only. Watch /v1/cost/by_agent
  • Requires an OpenAI-Project: <team>/<project> header, set via WANDB_PROJECT

Get a key:

  1. Go to wandb.ai/authorize
  2. Sign in with Google, GitHub, or email
  3. Copy the API key shown
  4. Note your team and project names — they form WANDB_PROJECT as <team>/<project>

5. OpenRouter one key, many models

  • 24 free models with :free suffix. Best: nvidia/nemotron-3-super-120b-a12b:free ★ default (262K ctx), nousresearch/hermes-3-llama-3.1-405b:free, qwen/qwen3-next-80b-a3b-instruct:free (262K), openai/gpt-oss-120b:free, google/gemma-4-31b-it:free, meta-llama/llama-3.3-70b-instruct:free
  • Free tier: 20 RPM · 50 RPD per free model (200 RPD if you've ever added $10 credit)
  • Free models share a daily pool — switching models doesn't reset

Get a key:

  1. Go to openrouter.ai
  2. Sign in with Google or GitHub
  3. Keys → Create Key → copy the sk-or-… key

6. Ollama (local)

  • Runs on your machine — zero rate limits, zero cost, 0ms cooldown
  • Default: gemma4:31b

Set up:

  1. Install: ollama.com → download for your OS
  2. Pull a model: ollama pull gemma4:31b (or llama3.2, phi4, etc.)
  3. Verify: ollama list
  4. The gateway auto-detects via OLLAMA_URL (default: http://localhost:11434)

Configuration (.env)

The gateway reads from .env. All keys are optional — providers without keys are skipped.

GEMINI_API_KEY=...
GEMINI_MODEL=gemini-3.1-flash-lite-preview

NVIDIA_API_KEY=...
NVIDIA_MODEL=deepseek-ai/deepseek-v3.2

GROQ_API_KEY=...
GROQ_MODEL=llama-3.3-70b-versatile

OPEN_ROUTER_API_KEY=...
OPENROUTER_MODEL=nvidia/nemotron-3-super-120b-a12b:free

WANDB_API_KEY=...
WANDB_PROJECT=your-team/your-project
WANDB_MODEL=zai-org/GLM-5.3-Flash
ROUTER_WANDB_MODEL=openai/gpt-oss-20b

OLLAMA_URL=http://localhost:11434
OLLAMA_MODEL=gemma4:31b

LLM_ORDER=gemini,wandb,groq,openrouter,nvidia,ollama
GATEWAY_PORT=8109

How failover works

  1. Caller sends request (with or without provider).
  2. Router estimates token usage from prompt length.
  3. Walks providers in LLM_ORDER, skipping any that:
    • Are inside their per-provider cooldown window (cooldown = 60/RPM)
    • Have hit RPM, RPD, TPM, or daily token cap
    • Have a max_ctx smaller than the prompt
  4. First eligible provider gets the call. On 5xx / timeout / 429 → moves to next.
  5. If provider=... was explicitly set, no failover — error surfaces.
  6. Every call (success or fail) is logged to gateway.db with provider, model, tokens, latency, status.
